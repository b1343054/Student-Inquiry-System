# Student-Inquiry-System

 📌 專案簡介
本專案為實習期間獨立研發的自然語言數據檢索工具。為降低非技術人員直接編寫 SQL 查詢資料庫的門檻，使用者僅需輸入日常口語需求（例如：「商學院總人數」、「睡眠時長低於 7 小時的男生」），系統即可自動解析語意、動態生成標準 SQL 查詢語句，並即時於前端呈現清洗後的統計圖表。

> 註：本專案資料源自實習合作項目，底層原始問卷包含簡體中文資料；系統後端實作了「繁簡語意雙向相容與智慧 Mapping」，使用者輸入繁體或簡體皆能精準檢索。

---

🛠️ 技術棧 (Tech Stack)
- **開發語言**：Python 3.x
- **前端介面**：Streamlit
- **語意匹配**：TF-IDF、餘弦相似度 (Cosine Similarity)
- **資料處理**：Pandas, PandasSQL, 正規表達式 (Regex)
- **雲端部署**：Streamlit Community Cloud (CI/CD 自動化建置)

---

 ✨ 核心功能與亮點
1. **自然語言轉 SQL (Text-to-SQL)**：智慧識別關鍵字，精準捕捉性別、年級（大一至大四）、學院及各類比較運算（超過、低於、介於等條件），動態拼裝 WHERE 條件語句。
2. **智慧多表關聯 (Smart JOIN)**：依據查詢條件自動判斷是否需要跨表關聯 `qustionnaire_result`，大幅提升資料庫檢索效能。
3. **聚合統計與分組**：支援 `COUNT`、`AVG`、`MAX`、`MIN` 及多維度分組運算（如各學院人數統計、各年級平均時長）。
4. **查詢歷史追蹤**：側邊欄自動記錄查詢歷史與生成的 SQL 語句，方便快速回溯比對。
